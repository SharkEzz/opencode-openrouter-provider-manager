Transparent square glyph trigger — panel headers, toolbars, row affordances. Always pass `label`.

```jsx
<IconButton label="Split editor" size="md"><Icon name="columns-2" size={14} /></IconButton>
```

Muted slate glyph at rest, cyan on hover, cyan tint + 1px cyan rim when `active`. Never use it for a labelled primary action — that is `Button`.
