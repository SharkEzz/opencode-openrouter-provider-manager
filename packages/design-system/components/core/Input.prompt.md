Filter / search / value field. Use `bare` inside a command palette header, boxed everywhere else.

```jsx
<Input size="lg" bare leading={<Icon name="search" size={16} />} placeholder="Route to model…" trailing={<Kbd>esc</Kbd>} />
```

Focus raises a 1px electric-blue border plus a soft blue glow. `invalid` swaps the border to crimson. Placeholder copy is lowercase with a trailing ellipsis.
