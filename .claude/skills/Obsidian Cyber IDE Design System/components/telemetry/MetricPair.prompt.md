Stacked label/value telemetry readout. Use in status bars, inspector headers and provider cards.

```jsx
<MetricPair label="in / out" value="$0.11 / $0.55" unit="/M" tone="telemetry" align="right" />
```

Right-align metric pairs when they sit in a trailing column so the digits form a clean rule. Values always carry tabular figures; never centre a column of numbers.
